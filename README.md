# Windows 11 DoH & DNS Manager

Скрипт автоматизации для настройки зашифрованного протокола DNS-over-HTTPS (DoH) в Windows 11. Утилита позволяет в один клик назначить безопасный DNS-сервер для проводной сети (Ethernet) или Wi-Fi, синхронизируя параметры напрямую со службой `Dnscache` и системным реестром Windows 11.

##  Возможности

* **Автоматическое повышение привилегий:** при обычном запуске скрипт самостоятельно запрашивает права администратора через системное окно UAC.
* **Корректная интеграция с Windows 11:** прописывает параметры шифрования не только в глобальный каталог `DnsClientDohServerAddress`, но и во внутренние ветки интерфейсов `InterfaceSpecificParameters` — в стандартном приложении «Параметры Windows» корректно загорается статус ручного шаблона.
* **Динамический поиск оборудования:** скрипт игнорирует виртуальные адаптеры (Hyper-V, VMware, VirtualBox, TAP, TUN, VPN) и автоматически выбирает активный физический сетевой адаптер.
* **Сброс в один клик:** возможность вернуть получение DNS по DHCP для любого интерфейса с полной очисткой ключей DoH из реестра.
* **Встроенная диагностика (пункт 4):**
  * Просмотр назначенных DNS-адресов на всех адаптерах.
  * Проверка фактического статуса шифрования (DoH активен / незашифрован).
  * Тест доступности сервера по TCP-порту 443 (HTTPS) с таймаутом.
* **Цветовая индикация:** системные операции и статусы выводятся зеленым цветом, любые сбои или отсутствие шифрования — красным.

---

##  Требования к системе

* Операционная система: **Windows 11** (любая редакция с поддержкой DoH).
* Права администратора на ПК.
* PowerShell 5.1 (встроен в Windows по умолчанию).

---

##  Установка и запуск

1. Скачайте файл `dns_manager.bat` из этого репозитория (или склонируйте проект).
2. Запустите `dns_manager.bat` двойным кликом мыши.
3. В появившемся окне контроля учетных записей (UAC) подтвердите предоставление прав администратора.
4. В открывшейся консоли выберите нужный пункт:

```text
=========================================================================
  [1] Подключить DNS и шифрование для проводного интернета (Ethernet)
  [2] Подключить DNS и шифрование для текущего Wi-Fi подключения
  [3] Очистить текущие настройки DNS (для Ethernet или Wi-Fi)
  [4] Показать статус текущих DNS-подключений и их шифрования
  [0] Выход из программы
=========================================================================

Скрипт и этот файл написаны с помощью Gemini Argon
